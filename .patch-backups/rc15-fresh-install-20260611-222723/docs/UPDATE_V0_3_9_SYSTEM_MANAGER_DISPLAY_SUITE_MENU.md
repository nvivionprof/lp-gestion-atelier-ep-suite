# V0.3.9 — System Manager affichage dynamique / menu Suite / checks

## Contenu
- Affichage dynamique plein écran type ToolMag.
- Rouge réservé aux anomalies bloquantes ou situations problématiques.
- Orange pour vigilance/anomalie non bloquante.
- Bleu/gris pour utilisation normale.
- Filtres zone et sous-zone sur l'affichage dynamique.
- Menu déroulant « Applications » visible hors menu admin dans System Manager.
- Filtrage d'affichage des liens selon les droits connus de l'utilisateur System Manager.
- Les checks de prise de poste/restitution ne sont plus précochés sur la réponse attendue.

## Notes
Le contrôle d'accès définitif reste assuré par chaque application et par LP Core. Le menu « Applications » est un raccourci ergonomique filtré côté interface.
