# Safety Manager V1.9 — Affichage dynamique public

Cette version ajoute des vues publiques Safety Manager accessibles sans connexion :

- `/affichage/` : affichage dynamique grand écran, rafraîchi toutes les 15 secondes ;
- `/public/` : tableau de bord sécurité synthétique ;
- `/consignes/` : tableau réglementaire de consignes sécurité ;
- `/declarer-public/` : déclaration rapide accident / incident / presqu’accident.

Les vues publiques n’affichent pas les informations personnelles détaillées. Les événements déclarés sans connexion sont enregistrés au statut “à analyser” et doivent être qualifiés ensuite par un responsable connecté.

Le visuel reprend le second mock-up validé : logo établissement en haut, compteurs sécurité, priorités 1 à 4, actions de prévention, consignes et cadre bordeaux transparent en bas à droite.
