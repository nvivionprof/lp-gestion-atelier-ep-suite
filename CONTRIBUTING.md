# Contribuer

## Avant de contribuer

1. Lire le README.
2. Vérifier les issues existantes.
3. Créer une branche dédiée.
4. Documenter les changements.

## Convention de commit simple

Exemples :

```text
feat(tp-manager): ajout des listes extensibles
fix(core): correction du menu principal
docs(install): précision sur Docker Compose
security(core): durcissement des paramètres session
```

## Règles

- Pas de données réelles dans les tests.
- Pas de secrets.
- Documentation mise à jour.
- Les migrations doivent être explicites.
- Les changements de déploiement doivent être signalés.
