# Licence à choisir

Le dépôt est prévu public, mais la licence doit être choisie explicitement avant publication réelle du code.

## Options courantes

### MIT

Très permissive. Autorise la réutilisation large, y compris commerciale, avec attribution.

### GPL-3.0

Impose le partage du code dérivé lorsqu’il est redistribué.

### AGPL-3.0

Variante adaptée aux applications web : impose aussi le partage du code source pour les services accessibles par réseau.

## Recommandation de principe

Pour une application web publique destinée à l’éducation et si l’objectif est d’éviter qu’un tiers privatise une version modifiée sans partage, regarder sérieusement l’AGPL-3.0.

Pour favoriser la réutilisation très large et simple, MIT est plus souple.

Ne pas renommer ce fichier en `LICENSE` tant que le choix n’est pas validé.
