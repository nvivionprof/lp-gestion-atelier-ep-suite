# Politique de sécurité

## Données interdites dans le dépôt

Ne jamais publier :

- fichiers `.env` réels ;
- mots de passe ;
- tokens ;
- certificats privés ;
- bases de données ;
- sauvegardes ;
- données élèves réelles ;
- photos ou médias nominatifs.

## Signalement

Créer une issue privée ou contacter le mainteneur du projet si une faille est identifiée.

## Avant publication d’une version

- Vérifier les secrets.
- Vérifier les migrations.
- Vérifier les dépendances.
- Vérifier l’impact RGPD.
- Vérifier la procédure de sauvegarde/restauration.
