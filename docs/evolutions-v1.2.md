# Évolutions V1.2

## Base élèves LP Core
- Import XLSX depuis l’interface LP Core : `LP Core > Importer Excel`.
- Bouton de synchronisation LP Core vers ToolMag après import.
- Endpoint interne ToolMag protégé par `LP_CORE_API_TOKEN`.

## ToolMag
- Fonction “Dupliquer / créer depuis modèle” sur les fiches matériel.
- Copie des informations générales, composants attendus, documents modèles, consignes et périodicités d’inventaire.
- Nouveau code inventaire généré ou saisi.
- Statut initial `À vérifier`.
- Aucun historique d’emprunt, maintenance, casse, intervention ou contrôle n’est copié.
- Prévisualisation obligatoire avant création.

## Utilisateurs
- Page “Montée de niveau / archivage” : boutons `Tout sélectionner dans le filtre` et `Tout désélectionner`.
