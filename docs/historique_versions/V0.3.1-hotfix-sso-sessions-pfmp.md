# LP Gestion Atelier EP Suite — Bêta V0.3.1 hotfix SSO/sessions/PFMP

## Type de livraison
Installation complète ou mise à jour complète par remplacement des fichiers applicatifs. Ce ZIP n’est pas une simple mise à jour de données.

## Corrections principales

- Isolation des cookies de session et CSRF par application : LP Core, Safety, PedaShop, System Manager, TP Manager et PFMP Manager.
- Correction LP Core : le formulaire de connexion accepte désormais `username` ou `code`, et renouvelle la clé de session à la connexion.
- Correction PFMP Manager : le formulaire de connexion accepte désormais l’identifiant `username` ou le `code` LP Core.
- Correction PFMP Manager : la connexion SSO LP Core renouvelle la clé de session et enregistre explicitement l’utilisateur PFMP.
- Allongement de validité du jeton SSO PFMP à 600 secondes par défaut.
- Nettoyage des sessions PFMP obsolètes quand l’utilisateur synchronisé n’existe plus.
- Ajout de `pfmp-db/data/.gitkeep` pour garantir le volume persistant PFMP dans l’archive.
- Correction de `scripts/apply_public_settings.sh` : les variables PFMP sont bien propagées lors d’une configuration publique/HTTPS.

## Conséquence normale après installation

Les anciens cookies peuvent rester dans le navigateur. Après déploiement, il est recommandé de vider les cookies du site ou d’ouvrir une navigation privée pour le premier test, puis de se reconnecter à LP Core.


## Script d'aide inclus

- `./scripts/apply_hotfix_v0.3.1_sessions_pfmp.sh` : applique les variables de cookies, reconstruit LP Core, PFMP et la passerelle, puis lance les migrations LP Core/PFMP.
- `./scripts/diagnose_pfmp_session.sh http://localhost:9000` : vérifie rapidement que `/pfmp/` est bien routé vers PFMP et que les cookies PFMP sont distincts.
