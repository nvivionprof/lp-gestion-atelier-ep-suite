# PedaShop V2.0 — accès public, stock, bons et inventaire renforcés

- Tableau de bord public sans connexion avec boutons masqués.
- Consultation stock publique, vue par référence ou par magasin.
- Filtrage des magasins visibles par utilisateur.
- Import/export XLSX + modèle XLSX.
- Bons avec rôles : élève, magasinier, professeur, admin.
- Retours détaillés : OK, usé, HS, perdu.
- Inventaire qui ne modifie que le stock réel physiquement présent.
- Modification article possible avec droits PEDASHOP_ARTICLE_EDIT / PEDASHOP_TEMP_ARTICLE_EDIT.
