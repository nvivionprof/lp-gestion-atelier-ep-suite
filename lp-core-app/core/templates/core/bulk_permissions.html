Gestion par lot — droits, magasins, habilitations et RGPD

Fonctionnement

Cette page applique une action à tous les utilisateurs cochés, ou à tous les utilisateurs filtrés si aucun utilisateur n'est coché.

  • Droits : ajout ou retrait des codes de droits consommés par les modules.
  • Rôle principal : modifie le rôle de base LP Core : élève, utilisateur, magasinier, professeur, responsable ou administrateur.
  • Magasins : affecte les magasins LP Core aux utilisateurs. Les magasins global sont transversaux, les magasins pedashop ou toolmag ciblent un module.
  • Certifications : ajoute une habilitation/certification à tout le lot.
  • RGPD : règle en masse le droit à l'image et les blocages photo/document.
