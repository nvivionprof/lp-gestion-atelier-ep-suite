Gestion des élèves et utilisateurs

  • Créer ou modifier une fiche utilisateur depuis Utilisateurs.
  • Utiliser Gestion élèves / montées pour les changements de classe, formation, groupe ou année scolaire.
  • Utiliser les actions par lot pour appliquer un droit, une habilitation ou un accès module à une sélection filtrée.

Import, montée de niveau et synchronisation

  • Importer une base élèves depuis Excel lorsque la structure est conforme au modèle.
  • Préparer les montées de niveau en filtrant par formation, classe et année scolaire.
  • Synchroniser ensuite les modules afin que ToolMag, PedaShop, Safety, System Manager et TP Manager récupèrent les comptes.

Administration de la suite

  • Régler les URL publiques et le portail dans URLs / HTTPS.
  • Utiliser Sauvegardes pour préparer une restauration complète.
  • Utiliser Base SQL uniquement pour une reprise technique contrôlée.

Cette aide doit être ajustée à chaque évolution du module.
