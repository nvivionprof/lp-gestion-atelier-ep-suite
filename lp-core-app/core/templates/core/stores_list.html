Magasins / droits / certifications

LP Core porte les droits et les périmètres communs. Les magasins peuvent être affectés à un module précis ou être déclarés Tous modules. Les modules synchronisés consomment ensuite ces magasins pour limiter les accès.

Fonctionnement par module

  • Magasins : global = visible par tous les modules compatibles ; pedashop = PedaShop seulement ; toolmag = ToolMag seulement.
  • Droits : codes synchronisables vers les modules, par exemple PEDASHOP_PROF, PEDASHOP_MAGASINIER, TOOLMAG_PROF.
  • Certifications : habilitations et autorisations portées par LP Core, consommables par Safety, ToolMag, PedaShop ou System Manager.
  • Règles modules : contrôlent les modules visibles depuis le portail LP Core. Elles ne remplacent pas les droits internes des modules.
