# Services applicatifs

Chaque dossier de `services/` correspond à un service applicatif de la suite.

Structure cible minimale d’un service Django :

```text
service-name/
├── Dockerfile
├── requirements.txt
├── manage.py
├── config/
├── app/
└── README.md
```

Les dossiers présents ici sont des emplacements réservés pour recevoir le code réel.
