Aide — System Manager

System Manager gère les systèmes pédagogiques, zones, réservations, QR codes et prises de poste.

Index

  1. Créer un système
  2. Réserver et utiliser un système
  3. Liaison avec les autres modules

Créer un système

  • Créer une fiche système avec zone, sous-zone, formation et informations techniques.
  • Ajouter photo, documents, points de contrôle et consignes associées.
  • Utiliser le QR code pour accéder rapidement à la fiche ou à la prise de poste.

Réserver et utiliser un système

  • Consulter le calendrier pour vérifier les disponibilités.
  • Créer une réservation en précisant période, groupe, enseignant et usage pédagogique.
  • Tracer la prise de poste, la restitution, les anomalies et l’historique.

Liaison avec les autres modules

  • Synchroniser LP Core pour les comptes et droits.
  • Partager les systèmes avec TP Manager et Sequence Manager pour planifier les activités.
  • Utiliser Base SQL uniquement en maintenance ou reprise contrôlée.

Cette aide doit être ajustée à chaque évolution du module.
