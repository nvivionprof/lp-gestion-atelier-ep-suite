# ToolMag V22 — inventaire utilisateur après sortie magasinier

Corrections principales :

- après validation de sortie par le magasinier, le QR code ouvre d’abord l’inventaire utilisateur de sortie ;
- une fois l’inventaire de sortie utilisateur soumis, le QR code ouvre l’inventaire utilisateur de retour ;
- l’affichage dynamique indique si l’inventaire utilisateur de sortie est fait ou à faire ;
- l’affichage dynamique indique également si l’inventaire utilisateur de retour a été soumis ;
- les pages de contrôle affichent explicitement l’état des inventaires utilisateur.

Version visible attendue : **ToolMag V22 - 2026-05-17**.
