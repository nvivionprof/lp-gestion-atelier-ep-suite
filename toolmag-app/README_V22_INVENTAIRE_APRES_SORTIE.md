# ToolMag V22 — inventaire utilisateur après sortie magasinier

Cette version corrige le flux demandé : le magasinier valide d’abord la sortie. Ensuite, l’utilisateur connecté scanne le QR code du matériel composé et effectue l’inventaire utilisateur de sortie. Une fois cet inventaire réalisé, le scan suivant mène vers l’inventaire utilisateur de retour.

L’affichage dynamique ajoute deux colonnes : inventaire sortie et inventaire retour.
