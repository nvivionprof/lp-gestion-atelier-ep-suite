# ToolMag V25

Améliorations :

- Tableau de bord : affichage de l'état des inventaires utilisateur de sortie et de retour.
- Affichage dynamique : les matériels simples affichent `S.O.` pour les inventaires utilisateur.
- Inventaire utilisateur : formulaire toujours vierge, avec composants cochés présents par défaut.
- Inventaire utilisateur de sortie : impossible tant que le matériel n'a pas été sorti par un magasinier.
- Formulaires magasinier : checklist préremplie depuis l'inventaire utilisateur soumis, ou à défaut depuis le dernier inventaire magasinier connu.
