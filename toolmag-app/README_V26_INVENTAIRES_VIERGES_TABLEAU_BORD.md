# ToolMag V26 — inventaires utilisateur vierges et vérification tableau de bord

## Changements

- Le tableau de bord met en rouge les matériels composés sortis dont l’inventaire utilisateur de sortie n’est pas fait.
- Les matériels simples sans composants affichent toujours `S.O.` pour les inventaires.
- Les inventaires utilisateur de sortie et de retour sont toujours vierges : aucune case n’est précochée. L’utilisateur doit cocher chaque composant réellement présent.
- Les formulaires magasinier continuent à être préremplis avec l’inventaire utilisateur soumis, ou à défaut avec le dernier inventaire magasinier connu.

## Règle métier

- L’utilisateur contrôle et coche ce qu’il voit réellement.
- Le magasinier relit, valide, corrige si besoin et statue.
